# Aleena Jasmy – Web Design Portfolio

Each website lives in its own folder. The home page (`index.html`) lists them as clickable cards.

- `index.html` – portfolio home
- `aurel/` – AUREL furniture store

## Add a new website
1. Create a folder, for example `my-new-site/`, with an `index.html` inside.
2. Add a line to the `projects` list in the root `index.html`.
3. Commit and push. The site updates in about a minute.
